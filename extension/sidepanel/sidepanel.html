Welcome to Glide

Glide needs your local backend running (it safely holds your Gemini API key).

  1. Get a free key at aistudio.google.com/apikey
  2. In backend/: npm install, copy .env.example → .env, paste your key
  3. Run npm start (starts localhost:8787)
